# CSC 299 Portfolio

This repo is my final project portfolio for CSC 299. I built each project below with Claude Code and published it on GitHub.

## Projects

### 1. Expense Tracker (main project, 5+ rounds)
**Repo:** https://github.com/rohan1031p/expense-tracker

A web app for logging expenses and managing a budget. I built it over several rounds, adding features and fixing problems each time.

### 2. Snake Game
**Repo:** https://github.com/rohan1031p/snake-game

A simple Snake game where players control the snake, collect food, and try to avoid crashing.

### 3. Task Manager CLI
**Repo:** https://github.com/rohan1031p/task-manager-cli

A command-line app that lets users add, view, complete, and delete tasks from the terminal.

## Project developed further: expense-tracker

Over 5+ rounds of development, I improved the Expense Tracker by adding new features and updating earlier requirements. These changes included category and month filters, category budgets, and better ways to manage expenses. I also added tests to check that the new features worked correctly.
